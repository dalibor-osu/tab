    Text
    Search Typing an address (github.com, localhost:3000, https://…) opens it directly; anything with a space is a search. Start with ? to force a search. Ctrl+Enter opens the result in a new tab. For a custom engine, use %s in the URL where the query should go. With history on, recent sites and searches show up under the box while you type - sites first.
    Icons Shortcut icons are the sites' own favicons. With the fallback on, DuckDuckGo's icon service is asked when a site has none; when off, only the site itself is contacted.
    Commands Type / in the search box to run one. A search command takes the rest of the line as the query; an open command opens all of its links in new tabs.
    Custom CSS Your rules are added after the page's own styles, so they win on equal specificity - use !important if a rule doesn't take. Changes apply as you type and stay in this browser. If something goes wrong, open the page with ?safe to load it without your CSS.
    Safe mode is on (?safe in the address), so your CSS is not applied on this load.
    Presets A preset is a saved copy of your setup: styling (look, background, custom CSS), content (texts, search engine), shortcuts, commands and widgets. Save one, then load all of it or only the parts ticked below. Presets imported from a file may hold only some parts - the row tells you which. Search history is never part of a preset.
    Grid Widgets sit on a grid that covers the whole screen. Every widget is sized in cells, so more cells mean smaller widgets. Use “Arrange widgets” to drag them around and to resize them by grabbing any edge or corner.
    Widgets Clock, date, notes and to-do widgets are built in. An external widget runs code someone else wrote inside a sandbox: it cannot read this page or your data and has no network access unless you allow specific hosts for it.
    Backup & sharing Export writes a file with only the parts you pick - share just your styling, or take everything as a backup. Importing takes all the file holds, either straight into this setup or as a new preset you can then load piece by piece. Search history is never included; it has its own export below.
    Search history Recent searches and sites belong to this browser only - they are not part of exports or presets. Use these to carry them to another browser; importing adds the entries to the ones you already have.
    Extension Chromium keeps the cursor in the address bar on a new tab and only lets a freshly opened tab take it. With this on, each new tab is reopened that way so the search box is focused, at the cost of the address bar showing the extension's address instead of staying empty.

    Add Command

    Letters, numbers, - and _ only. You run it as /name.
    Shown next to the command when you type / in the search box.
    Use %s where the query should go.

    This code runs on your computer every time you use the command. Never paste code you do not fully understand or trust.

    Runs in a sandbox and talks to the page only through the tab object. Always available: tab.args (the text after the command), tab.open(url), tab.search(text, newTab), tab.toast(text). Everything else below returns a promise, so use await. A returned value is shown as a toast, and the command ends when your code finishes.
    Settings: tab.settings.get() / set({…}). Shortcuts: tab.shortcuts.list() / add(name, url) / remove(name). Commands: tab.commands.list(). History: tab.history.list() / add(text) / clear(). Widgets: tab.widgets.list() / update(id, {…}). Clipboard: tab.copy(text) / tab.paste(). Browser tabs (extension): tab.tabs.list() / open(url) / activate(id) / close(id). Bookmarks (extension): tab.bookmarks.search(text) / add(title, url). The extension asks for the matching browser permission when you save.
    This website version will eventually stop being supported. Development continues in the browser extension. Get it on GitHub

About

Dalibor's default browser tab page

What is this?

This page started as a personal project just for me because I was annoyed about default browser new tab pages and wanted to create my own solution. Later, I decided to put a bit more effort into this and make it available and customizable for everyone while holding on to my core principles: simplicity, security and privacy.

This page consists of a simple statically served pages optimized for quick loading and privacy. Nothing you configure or do here leaves your browser.

How to use it

  • Search - In the middle there's a simple search box for browsing the web. It simply redirects you to search engine of your choice with the provided search term.
  • Shortcuts - Under the search box, you can find shortcuts. You can add them by clicking on the + sign and filling a name and link the shortcut should point to. Remove them by clicking on a red x in the top right corner.
  • Customization - The whole page can be configured using the configuration modal. Open it by hovering over the bottom right corner of the page and clicking on ⚙ button.

Privacy

Privacy is basically the main reason why I built this page. That should be self explainatory, I guess? Just to make it explicit:

  • No settings leave your browser
  • No search history leaves your browser (at least not from this website)
  • This website does not use any cookies
  • Everything you configure, including images, fonts, etc. stays saved locally
